### 🛒 Brazilian E-Commerce Analysis

**Tools:** PostgreSQL · SQL · Power BI

Analyzed the Brazilian Olist e-commerce dataset to explore revenue trends, product categories, customer spending, delivery performance, and payment behavior. I used SQL joins, CTEs, aggregations, window functions, RANK(), LAG(), and CASE WHEN to answer business questions, then built interactive Power BI dashboards to present the findings. The analysis highlighted key revenue-driving markets and categories while showing that delivery speed had a stronger relationship with customer satisfaction than payment method.
